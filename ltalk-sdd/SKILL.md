# LTalk 规格驱动开发与验收

## 项目意图与适用范围

用 Java Socket 和 Swing 实现一个单服务端、多桌面客户端的聊天系统，演示真实的连接、并发、消息路由与断线恢复。课程基础场景是 5～10 个局域网客户端。当前产品还覆盖账号、好友离线留言、独立群组、授权历史、附件和可选的单机公网 TLS。用户决定本轮功能与交付范围。

以下规格和评测集以功能提交 `8bc1f94` 为课程基线，使用 Java 17 编译目标、TCP 协议 v7、UDP 发现 v1 和 SQLite 表结构 v2。用于后续开发时，先按 [项目约定](../AGENTS.md) 读 [STATUS](../docs/STATUS.md)，再读 [README](../README.md)，查看 Git 状态及 [DEVLOG](../docs/DEVLOG.md) 的相关阶段。拟定新规格时查 [需求](../docs/requirements.md) 和 [路线图](../docs/ROADMAP.md)，用实际代码、测试和结果核实当前能力。

## 从意图到代码

1. **确定意图与范围。** 写明角色、使用场景、用户要完成的动作和期望结果。区分本次目标、要保持的既有约定、可逆假设与待决事项。只有当疑点会改变用户可见行为、权限、兼容性或数据结果时，才向用户确认相关边界。
2. **把需求写成可验收规格。** 为功能、性能及安全约束分配需求编号，注明初始状态、触发动作、输入范围、成功结果、拒绝或失败时的状态，以及数据和版本兼容条件。用接收方数量、错误码、消息 ID、数据库重启结果等可观察事实写通过标准。性能目标先约定场景、并发量、持续时间和度量方式，阈值取自项目规格或用户要求。
3. **先设计评测，再让 AI 编码。** 将每条新增或变更的规格关联到正常、边界和错误用例。仅改界面时沿用业务语义与协议。涉及权限、协议或持久化时，沿客户端入口、服务端校验与路由、存储和返回结果梳理影响，并在 [设计](../docs/design.md) 或 [协议](../docs/protocol.md) 中定位契约。实现与更新测试后，先运行受影响的用例，再回归。Swing 与会话展示状态在 EDT 更新，网络和文件操作在后台执行。
4. **处理偏差并保存证据。** 结果与预期不符时，先确认规格、环境和测试数据。实现有误就修复后复测；意图或边界有误就回到需求，重新确定规格及通过标准。保留关键断言，把已通过、失败和未执行分别记录。按项目约定更新交接与开发日志，再提交通过验证的独立改动。仅做验收或报告时，按现有证据取材，并为缺少证据的项目标记待验证。

需要人工审批的高风险动作包括修改线上防火墙或认证设置、停服换版、迁移或清除真实数据、向外部仓库公开发布。执行前列出目标、影响、备份验证与回退方式，获得相应授权后执行。等待期间可使用本机回环和临时数据验证。命令样例、历史部署记录和课程建议用于解释步骤。

## 基线规格与评测集

表中用例使用独立临时数据目录、回环地址和测试账号。三方场景以 Alice、Bob、Carol 区分发送方、接收方和旁观者。自动化入口位于 `src/test/java/cn/ltalk`。将本次需求与对应行关联，按影响补齐覆盖。

| 需求 | 验收用例与通过标准 | 自动化入口 |
| --- | --- | --- |
| F01 连接、认证与会话身份 | 连接后注册并登录，收到 `LOGIN_OK` 才进入聊天；用同名开启第二个连接，登录被拒且原会话可继续聊天。未认证连接发送聊天请求时收到 `NOT_AUTHENTICATED`，请求无投递。 | `AccountFlowTest`、`ChatServerTest` |
| F02 公共群聊、私聊与离线留言 | 三个账号在线时，公共消息各端收到一次。Alice 与 Bob 建立好友关系后，私聊仅双方收到，Carol 的历史中也没有该消息。Bob 离线时仍可留言，重登后在自己的历史查到；离线陌生人无法接收留言。 | `ChatServerTest`、`SocialIntegrationTest`、`HistoryPersistenceTest` |
| F03 独立群与管理员 | 新群号是唯一的 10 位 ASCII 数字串。以超过 100 条消息的群为夹具，新入群成员最多补齐最近 100 条，并接收在群期间的消息；退群后仍可查询已授权的部分，后续实时消息不再投递。管理员可从多页名单筛选并转让给离线群成员；取消或候选已退群时，管理员归属保持原值。 | `SocialIntegrationTest`、`ChatWindowTest` |
| F04 历史隔离与持久化 | 用同一隔离目录重启后，账号可登录且授权消息 ID 与正文可重查。搜索和导出仅包含本人可见记录；删除当前私聊的本人记录后，对方仍可查阅自己的记录。模拟私聊归档写入失败，正文和双方可见关系一起回滚。 | `HistoryPersistenceTest`、`AuthenticationExportTest`、`SqlitePersistenceTest` |
| F05 撤回时限和授权 | 用测试时钟在服务端归档后恰好 60 秒撤回，原位置显示撤回提示；首次撤回超过 60 秒时收到 `RECALL_EXPIRED`。尝试撤回他人消息时正文保持原样。成功撤回后搜索不再返回原消息，新下载不获授权，重启后撤回状态仍在。 | `MessageRecallTest`、`AttachmentTransferTest`、`ChatWindowTest` |
| F06 图片和文件 | 选择图片或文件后点取消，无附件消息；确认后按权限上传和下载，原始字节一致。普通文件超过 50 MiB 或取消传输时无附件消息，正常聊天继续。手工分别选取超过 12 MiB、超过 2400 万像素的图片，确认出现对应拒绝提示且未发布。 | `AttachmentTransferTest`、`AttachmentIntegrationTest`、`ChatWindowTest`，另做上述图片边界的手工评测 |
| F07 桌面响应与导航 | 在宽屏浅色及窄屏深色下操作。宽度低于 760 逻辑像素时可从列表进入聊天并返回。切换会话后草稿按会话保留；打开有未读的会话定位到第一条未读，点击引用可定位本人有权查看的原消息。 | `ChatWindowTest`、`ThemeRenderingTest`、`ConversationStoreTest` |
| F08 连接发现与恢复 | 未指定地址时可发现本地服务器并选择，显式地址直接连接。静默丢包按配置触发心跳超时，服务端释放会话名额；正常空闲仍可聊天。手动重连同址同账号后，恢复此窗口的会话和草稿。 | `DiscoveryIntegrationTest`、`HeartbeatIntegrationTest`、`ChatWindowTest` |
| S01 帧约束与 TLS | 文本正文按 UTF-16 单元计，2000 单元可发送，2001 单元被拒。普通帧上限 16 KiB，指定头像帧上限 176 KiB。TLS 信任链或主机名不匹配时，连接在应用层认证前失败；未认证连接配额可在超时清理后重新占用。 | `MessageCodecTest`、`ChatServerTest`、`PublicConnectionTest` |
| S02 SQLite 兼容性 | 以包含群成员、待处理申请、历史与授权的 SQLite v1 夹具启动。迁移后旧群得到新群号，关联与原消息 ID 保留，重启后新群号稳定。未知表结构版本拒绝启动。 | `SqlitePersistenceTest` |
| P01 多客户端容量 | 课程规模用 10 个真实回环 Socket 检查群聊、私聊及停止清理。公网扩展用 100 个本机 TLS 客户端检查突发消息、10 个客户端重连及一个额外慢连接的清理。健康客户端收到全部预期消息且无意外断线。记录实测时间、投递量和耗时统计。真实云规格的容量需在对应环境另测。 | `LoadTest`、`PublicCapacityTest` |

## 一次规格驱动开发示例

**意图**是让管理员直接从群成员中挑选接任者，避免手输用户名出错。沿用 F03 的权限和现有 `GROUP_TRANSFER` 请求。将改动拆为分页名单、用户名片段筛选、有效选择确认三项。客户端在成员退出后清除失效选择，服务端在提交时核对当前管理员和目标成员身份。

**评测**使用 25 位成员的群，按用户名片段筛出排在第二页的离线成员。清空筛选，选中一位在线成员并令其退群，核对选择清除和提交按钮不可用。选择另一位成员后取消，核对原管理员仍可打开转让窗口。重新筛出离线成员并确认，群资料中的管理员应变为该成员。范围与当时结果见 [阶段 47 开发日志](../docs/DEVLOG.md#阶段-47-转让管理员和会话操作文案2026-11-18本轮记录) 和 [桌面回归记录](../docs/test-report.md#近期桌面交互回归)。

## 运行与记录

从项目根目录运行。完整回归需要回环 TCP 和图形桌面，依赖未缓存时按 README 准备 Maven 及依赖。

```powershell
powershell -NoProfile -File .\build.ps1 -o '-Dtest=ChatWindowTest#administratorCanBrowseAllRosterPagesSearchAndTransferToAnOfflineMember' test

powershell -NoProfile -File .\build.ps1 -o package
```
