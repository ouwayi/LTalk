## 连接与账号

1. 在启动页输入服务器地址和端口，点击「连接服务器」。同机演示用 `127.0.0.1:9000`。跨设备局域网连接时填**服务端设备**的局域网地址。公网直连时勾选「使用 TLS 加密连接」，填写与服务器证书一致的域名或 IP。
2. 没有预填地址时，客户端会先在后台发现局域网服务器。发现一台时尝试自动连接，多台时在「发现的局域网服务器」中选择。发现失败可手动填写。「最近连接的服务器」可重用最近 6 个握手成功的地址和 TLS 选项。
3. 首次连接某台服务器时，点击「立即注册」，填写昵称、用户名、密码及确认密码。用户名区分大小写，去掉首尾空白后须为 1～20 个英文字母、数字或下划线，也可让服务端随机生成。密码为 6～128 个 UTF-16 单元，支持符号。点击密码框旁的「显示/隐藏」可以核对输入。
4. 注册成功后客户端自动登录。已有账号时直接输入用户名和密码。输入有误时按界面提示改正后重试。账号和历史保存在所连接的服务端。

## 公共聊天室

- 登录后默认进入「公共聊天室」。左侧同名分类显示公共会话和当前在线的其他用户。「好友与群聊」显示好友和已加入的独立群。好友离线时仍会留在该分类。
- 在输入框键入消息，按 **Enter** 或 **Ctrl+Enter** 发送，按 **Shift+Enter** 换行。正文须含有非空白字符，最多 2000 个 UTF-16 单元（例如 😀 占两个）。各会话的草稿会保留在当前窗口。
- 气泡会显示「发送中」「已确认」「发送失败」或「结果待确认」。**已确认**指收到服务端回显。发送失败或待确认时可点「取回正文」。重发前可先重连并检查历史，同一消息重新发送可能产生重复记录。
- 窄屏下点击会话进入聊天页，再点左上角返回箭头回到列表。点击列表空白处会保留当前会话。

## 私聊与好友

1. 点击左侧搜索框旁的「+」打开「更多操作」，选择「查找用户」。可输入昵称或用户名的一部分，搜索忽略大小写。结果同时显示昵称和完整用户名。
2. 点「申请好友」。申请可发给离线用户，对方登录后可从「+」→「通知」接受或拒绝。成为好友后，从「好友与群聊」打开私聊。对方离线时仍可留言，对方下次查看该会话即可读到。
3. 与陌生人聊天时，先从在线列表打开私聊，在聊天标题下点「申请私聊」。对方从「通知」接受后，两人在线时可互发消息。对方离线时仍可查看旧记录，等对方上线后重新选择该会话再发送。

点击私聊标题、群消息头像或群成员可打开用户信息卡片，可发起私聊、申请好友或解除好友关系。点击卡片里的用户名会把原始用户名复制到剪贴板。私聊的「会话更多操作」可屏蔽或解除屏蔽陌生人私聊。

## 群组

- **创建和加入**。使用「+」→「创建群组」，填写群名并选择是否审核入群申请。创建者成为管理员。「查找群组」可用群名或完整的 10 位群号，也可留空浏览。开放群可直接加入，需审核的群由管理员在「通知」处理。
- **查看和邀请**。点击群聊标题打开信息卡片，查看成员和在线人数，点击群号可复制。选「邀请好友」后，被邀请者在「通知」决定是否接受。普通成员发出的邀请按群的审核设置处理，管理员的邀请在对方接受后直接入群。
- **管理与退出**。管理员可在群聊卡片修改审核设置、解散群组或转让管理员。转让时可在完整成员名单中按用户名筛选并选中接任者，再点「确认转让」。管理员先转让再退群，也可选择解散。其他成员可在群聊卡片选择「退出群聊」。
- **历史权限**。每次入群最多补齐当时最近 100 条，可继续接收在群期间的新消息。退群或群解散后，可从「+」→「列表外的会话」查看已获授权的旧记录。该入口也能打开离线陌生人的旧会话。

## 历史、搜索与未读

- 进入会话时先加载最近 20 条本人可见的消息。向上滚到顶部或点「加载更早消息」继续。公共会话可查看登录前或离线期间的公共消息，并遵循本人删除记录的设置。
- 点聊天上方的放大镜，按正文、发送者昵称或用户名搜索**当前会话**的可见历史。双击结果或点「定位消息」跳到原消息及其上下文。输入框右上方的向下箭头可回到最新消息。
- 打开有未读的会话会跳到本窗口收到的第一条未读，显示「以下为未读消息」。翻看旧消息时若有新消息，可点「有 N 条新消息」跳转。

## 消息操作

| 操作 | 入口与结果 |
| --- | --- |
| 引用回复 | 右键消息选「引用回复」。输入框会显示可取消的引用预览。发送后点击引用可定位本人有权查看的原消息。 |
| 复制正文 | 右键选「复制正文」，正文和换行一起复制。 |
| 撤回消息 | 本人发送的文字、图片或文件在发出后 60 秒内可右键撤回。原位置显示「[消息已撤回]」，停止授权新的附件下载。接收方已保存的文件副本仍保留。 |
| 删除这条信息 | 右键选择该项，隐藏本人归档中的这一条。其他参与者保留各自可见的记录。 |
| 删除所有聊天记录 | 在群聊信息卡片或私聊顶部的「会话更多操作」中选择。范围为本人在当前会话中的记录。删除结果待确认时，可使用「重新加载聊天记录」核对。 |
| 导出聊天记录 | 在群聊信息卡片或私聊顶部的「会话更多操作」中选择。另存为可选 JSON 或 CSV、文件名及位置，只导出本人在当前会话中可见的记录。覆盖同名文件前会请求确认。 |

JSON 文件是数组，每条记录占一行，可包含引用编号或附件信息。CSV 保留原七列，图片用「[图片]」表示。导出保留撤回提示。文件字段见[通信协议](protocol.md#导出文件布局2026-11-01)。

## Emoji 与附件

- **Emoji**。点输入栏的表情按钮，可插入 69 个内置彩色 Emoji。复制及发送保留原 Unicode 字符。[Twemoji 图形与许可说明](../src/main/resources/cn/ltalk/client/ui/emoji/NOTICE.txt)
- **图片**。点图片按钮，选择 PNG、JPEG、GIF 或 BMP，最多 12 MiB 和 2400 万像素。消息中可点击缩略图预览或保存原图，GIF 预览显示首帧。
- **文件**。点回形针选择文件，支持任意类型（包括图片），每个最多 50 MiB。接收方可在文件卡片上点「保存」另存。
- **发送与下载**。选择图片或文件后核对目标会话和文件名，再点「发送」。可在确认框取消，也可在传输过程中取消。下载以本人历史权限为准。退群后仍可保存已授权且未删除或撤回的附件。Windows 使用系统文件选择器，其他系统使用 Swing 选择器。

## 资料与外观

- **资料**。点击左下角本人头像 →「个人信息」，可改昵称、上传或重置头像。头像原图上限为 12 MiB 和 2400 万像素。保存后，联系列表、聊天标题和消息气泡会同步显示新资料。
- **修改密码**。在「个人信息」点「修改密码」，填写当前密码和两次相同的新密码。成功后当前会话继续使用，下次登录用新密码。
- **外观**。从左上角主菜单打开「外观设置」，可选浅色或深色、纯色或渐变。点色块拖动选色，也可直接填 `#RRGGBB`。预览后点「应用设置」。外观保存在本机的系统用户目录中。
- **退出和切换**。退出登录会清除当前窗口的身份和草稿，服务端归档仍可在下次登录时查看。切换账号时原会话保留到新账号登录成功。登录失败或点「返回聊天」会保留原账号和草稿。

## 断线重连

1. 客户端检测到断线后保留当前聊天页。点击顶部「重新连接」，使用原服务器地址和预填用户名重新登录。
2. 使用同一台服务器和同一账号时，恢复当前窗口所选的会话、草稿和发送状态，并重新加载本人可见的历史。
3. 若仍显示「结果待确认」，先在历史中核对这条消息。需要重发时，用「取回正文」恢复到输入框再发送。

正常停服时，客户端可通过 TCP 连接关闭发现断线。若网络持续失联且连接尚未关闭，则由双向心跳在本端探测超时后关闭连接。[心跳超时与复验](test-report.md#桌面手动复验)

## 常见问题

| 遇到的问题 | 可以检查什么 |
| --- | --- |
| 找不到服务器或连接超时 | 确认服务端已启动、地址和端口正确。自动发现失败时可手动填写。在局域网内连接其他设备时使用该设备的局域网地址。 |
| TLS 连接失败 | 核对服务端端口是否启用 TLS、证书有效期、地址匹配及本机 Java 是否信任签发方。 |
| 登录失败或提示同名会话 | 核对用户名大小写、密码和所连接的服务器。如果旧窗口仍在线，先退出旧窗口或等服务端清理已断开的连接。 |
| 图形客户端无法启动 | 在图形桌面中启动 Swing 客户端。无桌面的服务器可运行服务端进程。 |
| 发不了私聊或看不到旧消息 | 检查好友、私聊许可和在线状态。群组记录取决于入群后获得的历史权限，个人删除也会影响历史和导出。 |
| 保存附件或导出失败 | 检查保存位置是否可写、磁盘空间是否充足。文件下载还需要当前账号拥有该消息的历史访问权限。 |

端口、数据目录、日志和云端设置见[运行与部署](deployment.md)。服务端错误码见[通信协议](protocol.md#错误码)。
