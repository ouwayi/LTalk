## 已确定的方案、原因与界面偏好

- **栈与线程**：Java 17 兼容 API、Maven 单工程、Swing/Java2D、阻塞 TCP，控制课程依赖和 5～10 人目标规模；网络/密码计算/导出写文件在后台，展示经 EDT 回调。提交发送队列后清空输入，只显示服务端正式回显；不把入队/归档/回显当已读或可靠送达。
- **协议 v2**：UTF-8/LF JSON、Gson 2.11.0，16 KiB 帧、2000 UTF-16 char 正文；用户名 strip 后 1～20 位 ASCII 字母/数字/下划线且区分大小写；昵称 1～40 char、密码 6～128 char（不 strip）。默认 9000/0.0.0.0/20 连接（含未登录）、登录绝对期限 10 秒，客户端连接/登录默认 3/5 秒。两端一起升级，不兼容旧无密码登录。
- **身份**：保留名称预留 → LOGIN_OK → 就绪及私聊仅双方路由。PBKDF2-HMAC-SHA256 600000 次、16 字节随机盐、256 位输出；JDK 实现无新依赖。凭证是绑定账号的 TCP 会话，无独立 token/固定 TTL，断开或登出失效；身份由服务端绑定，不采信请求 from/userId 冒名。
- **存储与导出**：CLI 默认工作目录 `data/`，`-Dltalk.dataDir` 可指定稳定目录；`ChatServer.dataDirectory(Path)` 必须在 start 前设，程序化默认临时目录。账号与归档文件用用户名 UTF-8 十六进制键防止 Windows 大小写冲突；单目录服务端独占锁。归档先于投递、仅在线授权者可见，跨文件非事务；每连接一份固定末尾快照、一条一页，客户端流式 JSON/CSV，不积累全量历史。
- **心跳**：默认间隔 10000 ms、响应 20000 ms，属性 `ltalk.heartbeat.intervalMillis` / `ltalk.heartbeat.timeoutMillis`；只有匹配 PONG 完成本轮，聊天空闲不踢。检测约为间隔＋响应期限＋调度容差，无硬实时保证；不广播心跳，不自动重连/重发。
- **界面偏好与扩展**：中性项目命名，简洁分栏、蓝色强调、圆角、清楚消息层级、协调菜单；背景只纯色/渐变，可自选色，保留浅深色/窄屏和组件扩展点。网络路由与 ConversationStore/组件分开；多群需后端/协议/成员权限设计，不能只造假会话。
- **外观**：`${user.home}/.ltalk/appearance.properties` 只存外观，不存身份/密码/地址/聊天；浅深色各有色对、共用背景类型，坏配置回默认但不覆盖原文件；保存失败仍保留当前外观和草稿。

## 已知问题、边界及检查方式

| 项目与证据性质 | 复现/检查或处理方向 |
| --- | --- |
| 账号/导出 UI 人工证据未补齐 | 用独立服务端数据目录与独立测试客户端注册手填/随机账号，试错密码、重名、JSON/CSV、空记录及失败目录；核对文件/对端收包及重连后同账号归档，不能仅看成功提示 |
| 同步广播/归档（代码边界，未专项压力验证） | 不读取 Socket 的慢端可能拖慢其他业务写入；归档逐账号同步写、无跨文件事务，磁盘失败可能部分归档而返回错误。后续用隔离数据故障注入/慢端探针验证，不动真实账号文件 |
| 内存历史/滚动（代码观察） | `ConversationStore` 随进程累积；`MessageTimeline.showEntries` 总调用 scrollToBottom。大量记录、停在历史位置再收消息可检查卡顿/跳底，未做规模与阅读位置专项验收 |
| 小屏/高 DPI（代码观察） | AppearancePanel 460×572、设置对话框不可缩放；主窗口窄屏通过不等于设置或新增注册/导出对话框全部可达，需在较小可用区域/选定 DPI 实测 |
| 数据目录/文件边界 | 从不同工作目录启动会使用不同相对 data，账号可能看似消失；改用固定绝对路径。目录锁占用先停止原服务端，勿删除账号绕过；原子移动不支持、无写权限/坏账号/坏时间元数据可导致启动或保存失败，恢复流程未专项验收 |
| 身份/传输边界（已确认代码） | 明文 TCP、无 TLS/限流/找回密码；加盐存储不代表传输加密。新窗口不自动回放历史，昵称暂仅保存，不能据账号注册成功宣称这些功能完成 |
| 工具链/验证环境 | 离线 package 通过；clean 插件此前未缓存，离线 clean 未通过。JDK 25 native-access/Unsafe、Shade 重叠警告仍在。Socket 测试需要允许本机 TCP，沙箱连接拒绝后应在授权环境原断言重跑 |
