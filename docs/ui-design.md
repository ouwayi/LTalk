# LTalk 桌面界面设计与扩展说明

客户端采用组件化的 Java Swing 桌面界面，支持公共聊天室、独立群组、好友及授权私聊。展示层与 ChatClient、ClientEventListener、服务端及 common 消息模型分离。协议变更见 [通信协议](protocol.md)。

## 改造前与改造后

原界面集中在 ChatWindow：顶部 FlowLayout 连接配置，中间 JTextArea 统一显示群聊/私聊和系统消息，右侧 JList 在线用户，底部 JTextArea 与按钮。字号、颜色和边距直接写在窗口类里；没有按会话分组的本地展示状态。

界面由左侧会话栏与右侧聊天区组成：桌面侧栏宽度约为窗口的 28%，限制在 300～354 像素；右侧内容最大宽度 920 像素并居中。聊天标题栏和输入区为圆角浮动面板；对方消息居左，自己经服务端回显的消息居右。小于 760 像素时转为单列；最小窗口为 360×540。

语义色板集中于 ThemePalette，ChatTheme 负责按角色应用颜色：选中蓝为 `#3390EC`，浅色面板为白色、深色面板为 `#181818`、输入/次级面板为 `#242424`；暗色默认背景 `#101010 → #202020`，文字为 `#F0F0F0`、辅助/禁用文字为 `#B0B0B0`。蓝色保留为操作强调，主要暗色面板和气泡使用中性灰黑。文字、输入框、气泡、系统提示、禁用状态和滚动条均跟随当前窗口主题。常用 Emoji 从 JAR 读取彩色字形，其他缺失字形使用系统字体回退。聊天背景使用用户选择的纯色或渐变。工具图标和字母头像由 Java2D 绘制。

## 交互规则

- 左侧搜索匹配联系人昵称、用户名与最后一条消息摘要，隐藏列表项不会切换当前发送对象。联系人、私聊标题和气泡读取账号的最新昵称及头像，缺少图片时按昵称生成默认图标。群聊摘要按当前昵称呈现最后一条消息的作者。联系人或私聊标题悬停显示 `@用户名`，同名联系人仍以稳定用户名区分。
- 本人在「个人信息」中打开「修改密码」，填写当前密码、新密码和确认新密码。密码默认隐藏，可分别显示。提交时清空输入并等待服务端响应，失败在表单显示，成功关闭改密窗口并提示下次使用新密码。保持当前聊天和草稿，关闭资料窗口或会话结束时关闭改密窗口。
- 群聊事件按会话标识进入公共聊天室或对应独立群组。私聊按双方账号进入对应联系人会话。消息按服务端生成的消息 ID 去重。
- 提交后显示「发送中」气泡。按请求编号匹配的服务端回显将它替换为「已确认」气泡。显示「发送失败」或「结果待确认」时可取回正文，替换非空草稿需要确认。
- 断线提示位于会话列表与聊天区上方，窄屏也能从任一页面重连。点击「重新连接」使用原地址、端口和 TLS 选项并预填用户名。同址同账号重登恢复所选会话和草稿，根据服务器的社交状态和在线列表恢复发送权限。
- 后台窗口、未选中的会话、窄屏列表页和翻阅旧消息时收到的对方实时消息计入未读。进入会话定位首条未读时确认当时的一批消息。自己发送和历史加载的消息不计入未读。
- 输入框支持 Enter/Ctrl+Enter 发送、Shift+Enter 换行，随文本增高并在达到上限后内部滚动。发送后清空已提交文本、滚动到最新消息；输入校验失败保留草稿。
- 草稿按会话保存。好友离线时仍能发留言；已获许可的陌生人离线时保留聊天页与草稿，重新上线后需明确重选。切换身份成功后清除上一身份的窗口历史和草稿。
- 搜索框右侧的「好友与群组」打开查找用户、好友、请求、查找群组和创建群组。会话列表在有待处理的入站请求时显示数量。在线陌生人的聊天标题下提供「申请私聊」。群聊更多菜单根据成员权限显示邀请、审核设置、转让、退群或解散。
- 连接设置在独立启动页显示。登录后可从左上菜单返回连接页，侧栏底部为本人资料入口。
- 登录显示会话摘要和当前会话最近 20 条。切入其他会话时请求其最近消息。时间线上滚至顶端会继续加载，顶部「加载更早消息」也可触发。补入记录以首个可见消息的正文位置为锚点。
- 当前会话的放大镜打开搜索窗口，搜索服务器上本人有权查看的正文、昵称或用户名。可继续加载结果，双击或选中后按 Enter 定位。时间线显示目标及相邻消息，以蓝色边框标记目标。「返回最近消息」回到持续接收新消息的原时间线。
- 打开会话时，时间线在首条未读前绘制分隔提示。阅读旧消息期间收到新消息，顶部可点「有 N 条新消息」跳回首条未读。
- 右键消息可引用回复或复制完整正文。引用预览在输入区上方，可单独取消并保留输入的文字。点气泡内的引用定位原消息，未加载时打开该消息的历史上下文。
- 表情面板在光标处插入 Unicode Emoji。面板、草稿、消息气泡和左侧会话列表共用彩色资源。草稿的光标和删除键按完整的内置 Emoji 移动，会话摘要按字形实际宽度截断。输入区按可用宽度换行，单行正文和占位文字与两侧按钮垂直居中，多行达到上限后可滚动。
- 图片按钮使用图片专用筛选，回形针选择任意文件。两个传输入口使用可取消的进度窗口，窄屏也保留整个输入栏的工具入口。
- 图片气泡中的缩略图可点开预览。图片和文件气泡均可选路径保存。已显示的附件随历史分页、搜索和引用定位呈现。
- 时间线复用当前会话已有的气泡，并按可用宽度缓存测量结果，避免每次收消息重新创建所有富文本组件。复用按事件对象区分，不以内容、时间或 requestId 去重；切换身份或会话后丢弃不再显示的组件缓存。
- 时间线按原始相邻顺序、稳定发送者标识和本地日期分组。系统/错误提示也会分隔消息组。每组首条可见接收气泡显示昵称，同名账号保持各自的组。自己的消息保持右侧布局。
- 展示资料随连接同步，读取线程解码头像后交给 EDT。列表、标题和时间线复用同一份图像数据。更新后刷新现有气泡名和头像，以及群聊摘要。重新登录和切换账号时，旧会话的资料缓存会清理。新导入头像按原图短边选择 256×256 或 512×512，组件用双三次插值按布局尺寸绘制，兼容旧 48×48 与 144×144 图片。
- 左侧头像由时间线统一绘制，每个接收组一个。头像在消息组的垂直范围内，空间足够时贴近末条气泡或视口底边。当消息组只露出一小截时，视口裁去头像和气泡超出边缘的部分。相邻头像各在对应组内，整组离开后停止绘制。滚动使用视口重绘以反映头像位置。收新消息时，已经在底部则继续跟随，向上阅读时保留滚动位置。
- 外观切换仅更新展示状态与色板，不重建 ChatClient 或 ConversationStore；已有消息的气泡缓存按色板失效，确保旧消息也正确换色。不同窗口通过各自根组件持有色板，不使用全局可变主题。

## 外观设置与保存

通过「菜单 → 外观设置」打开设置；主菜单另有一键浅色/深色切换。用户可以选择纯色或渐变、预设颜色，或输入任意不透明 `#RRGGBB` 色值。每个色值旁的色块打开主题一致的选色浮层：色盘横轴为饱和度、纵轴为亮度，下方色相条；支持鼠标拖动、方向键微调，Escape/点击外部关闭。色值、色块与背景预览联动，非法输入保留用于修正，色块沿用最后合法颜色。设置面板维护草稿，仅点击应用才发布给聊天窗口，取消/关闭不发布；非法色值提示错误并禁用应用。纯色模式同时停用结束色字段和色块；切换模式、预设、恢复默认或移除组件时关闭旧浮层。

AppearanceSettings 分别保存浅色和深色背景色，模式切换不覆盖另一个模式的颜色；背景类型共用。AppearancePreferences 将版本、模式和色值写入系统用户目录 `.ltalk/appearance.properties`，通过同目录临时文件与替换避免留下半份配置。保存版本为 2，兼容读取版本 1；只有 v1 旧默认暗色对 `#111B27 / #213347` 换为墨黑，其余自选颜色和浅色配置保留，v2 明确选用旧色对也保留。读取不改写文件；遇到损坏、未知版本或超过 32 KiB 时回退默认。保存失败时外观仍可使用，并显示错误；不影响聊天草稿。

按钮家族（主操作、圆角次操作、图标按钮及开关）统一使用单次文字绘制；禁用时取当前窗口辅助文字色，消除 BasicButtonUI 在深色背景上产生的两层偏移浮雕。连接/登录以及发送、应用、资料保存、密码显隐、注册切换等入口共用该修复，不更改启用条件或网络行为。

设置为当前系统用户共享的本机偏好，新窗口启动时读取最近保存值；已运行窗口保持各自的显示状态。自动化测试使用临时目录，真实窗口验收使用独立测试用户目录，不覆盖实际用户配置。

## 后续功能接入位置

```text
既有 ClientEventListener → ChatWindow 适配 → ConversationStore → Summary / Entry → Swing 组件
界面发送 / 工具动作   → ChatWindow 适配 → 既有 ChatClient
```

1. **好友关系**：客户端通过 SocialChannel 与 SocialDialog 加载和操作好友、请求及群组状态，ConversationStore 按稳定用户名关联 ContactProfile。访问权限由服务端的 SocialStore 与 MessageRouter 校验。
2. **多个群聊**：ConversationId 的 GROUP 键区分公共聊天室和每个 UUID 群组。列表、时间线、草稿与历史分页沿用对应键，服务端依据群组成员权限选择实时接收者。已退出或解散的群聊在列表保留旧记录。
3. **附件和 Emoji**。图片与文件接入独立传输连接，`MessageTimeline` 呈现缩略图或文件名，数据由会话历史提供。Emoji 面板操作草稿，使用既有文本发送入口。
4. **历史容量**：本人授权归档由 ChatArchive 持久化，客户端按需分页，ConversationStore 在 EDT 保存已加载的展示状态。已展开的页面保留至本轮会话重载或身份切换。
5. **主题/布局**：颜色角色改 ThemePalette，样式绑定改 ChatTheme，外观选项与持久化分别改 AppearanceSettings/AppearancePreferences，背景绘制改 WallpaperPanel，菜单改 ChatPopupMenu，气泡改 MessageTimeline/MessageText，窄屏断点改 ResponsiveShell；不需要改 TCP 线程或服务端路由。

## 运行与验收

按 README 构建 `powershell -NoProfile -File .\build.ps1`，然后分别运行服务端和 `cn.ltalk.client.ChatWindow`。客户端先连接服务器，再注册或登录。登录后显示本人授权历史和实时消息。

自动化生成的界面预览位于 `target/ui-preview/ui-desktop.png`、`ui-narrow-chat.png`、`ui-narrow-list.png`，它们使用测试会话数据，不提交 Git。真实 Windows 窗口的 computer-use 验收过程与最终测试数见 [测试报告](test-report.md)。

另有暗色与菜单预览：`ui-dark-desktop.png`、`ui-dark-narrow.png`、`menu-light.png`、`menu-dark.png`、`appearance-settings.png`，均在同一预览目录。

## 独立启动页与个人信息（2026-10-30）

启动页左侧只有服务端 IP/端口和连接/断开，右侧默认为登录，可用「还没有账号？立即注册」切换为昵称、手填/随机用户名、密码和确认密码。预填地址时自动连接服务器；注册成功自动登录，登录成功才显示聊天页。桌面左右排列，窄屏上下排列且整体可滚动；配色跟随原有窗口主题。

聊天列表底部改为可点击的 UserIdentityButton，显示本人头像、昵称和 @用户名。菜单包含个人信息、退出登录和切换账号。ProfilePanel 显示用户名、昵称、头像、注册时间和服务器，支持上传图片、恢复默认头像和编辑昵称。个人信息窗口可缩放并滚动。2026-11-15 又加入跨客户端展示资料同步和本人改密。

退出登录清除窗口身份和聊天/草稿，回到登录页保留用户名。切换账号改为保留旧连接与消息/草稿，清空认证表单输入，候选验证成功后才退出旧账号；右上角返回聊天取消候选，失败也不退出旧账号。密码在取消/成功后清空并隐藏。连接设置入口显示启动页，当前仍登录时可返回聊天。无网络故障自动重连或自动凭证保存。

本轮组件渲染预览新增 welcome-login/register/dark/narrow/narrow-bottom、profile-footer/editor，均在忽略的 target/ui-preview；这是自动化组件与本机网络验证，不能当作用户人工验收或多机证据。

## 文件选择与密码显隐（2026-10-31）

头像选择在 Windows 调用系统 Common Item Dialog，左侧导航、顶部路径及搜索栏跟随系统外观，其他系统使用 Swing 选择器。当时的导出目录选择随后改为下节的「另存为」。密码和确认密码右侧各有显示/隐藏按钮，默认遮罩，换表单、清凭据或返回聊天后隐藏。

## 保留会话的账号切换（2026-10-31）

切换页标题为「切换账号」，提交按钮为「登录并切换」；原账号在线时右上角「返回聊天」始终可用，包括新账号验证中。待切换连接的错误只在表单显示，不写入原聊天记录；返回保留旧消息/草稿/未读，恢复旧地址；成功清除旧身份展示再显示新身份，用户名相同但服务端不同也隔离。原连接自身断线时返回按钮隐藏，不假装旧聊天仍可使用。

## 导出另存为（2026-11-01）

会话菜单导出直接进入保存窗口，不先选格式；同窗选择 JSON/CSV 与文件名/位置。Windows 用 IFileSaveDialog，其他系统用 Swing 保存窗口；按类型整理扩展名并对最终路径确认覆盖，确认前不开始写出。

## 登录历史、删除和保存（2026-11-01）

登录成功即分页加载本人历史，状态区显示加载进度/完成/失败；历史私聊对象离线仍显示记录且禁发。加载中可继续收发，消息 ID 合并避免重复，历史不算新未读。会话菜单提供重新加载，确认完成后可清空本人当前会话记录；右键消息可单条删除本人副本，删除确认说明不影响对方。删除失败不清界面，成功后重载核对；草稿不删除。

导出直接打开原生另存为，JSON/CSV 类型、文件名、位置同窗选择；按最终扩展名确认覆盖。JSON 为逐条换行的合法数组，不是 JSONL；CSV 既有转义保持。原生预览验证下拉和中文自定义路径返回，不宣称整个用户流程在多机/所有系统已验收。
