# LTalk 后续开发路线图

整理于 **2026-11-16（Asia/Shanghai）**，2026-11-19 更新至阶段 52。下一项产品功能由用户选定。[当前状态](STATUS.md) · [通信协议](protocol.md) · [测试报告](test-report.md)

## 1. 单机云部署、公网连接与约 100 人在线

- **部署形态**。同一个 Swing 客户端可连接局域网服务器，也可通过域名或 IP 连接云服务器。单台服务器可以通过一个 TCP 监听端口接入多个客户端，默认端口为 `9000`。各自部署的服务端各自管理账号和历史。若局域网用户和远程用户需要同一份数据，可让双方连接同一台服务端。
- **私网试用**。用户已在 Oracle Cloud Ubuntu 24.04 通过 Tailscale 验证宿主机与虚拟机连接、登录和收发。部署手册记录固定数据目录、版本更新和备份恢复。[单机云部署手册](deployment.md)
- **公网 TLS**。已提供证书校验、未认证连接上限、登录注册限流和 systemd 单元。Oracle Cloud 的双设备公网基本试用对应 `f89dc23`（v6）。本轮新版云端试用据用户反馈暂未发现问题，双设备逐项结果、接入网络与长期证书续签待核对。[新版云端试用](test-report.md#新版云端试用)
- **约 100 人在线**。TLS 模式默认 140 个总连接，最多 24 个未认证连接。已实现逐连接有界发送队列及慢连接淘汰。本机使用 100 个 TLS 客户端验证集中登录、重连、群聊突发和停止读取的连接。实际云规格的容量仍需按使用场景验收。[测试报告](test-report.md)
- **容量取舍**。每秒 5 条公共消息和 100 名在线用户约对应每秒 500 次实时投递和 5 次公共消息写入。服务器端还需处理登录、头像和历史加载，最终容量取决于实际负载和资源。

## 2. 启动与局域网自动发现

- Windows 双击入口已随构建打包。客户端启动时后台收集约 2 秒的 IPv4 局域网发现结果，候选包含名称和聊天 TCP 地址。
- 一台时自动尝试连接，多台时由用户选择。显式启动地址优先，连接失败或无响应可手动填写。「最近连接的服务器」保留 6 个通过 TCP 握手的地址。启动页提供 TLS、用户名及密码的填写说明。已连接后仍由用户登录。
- 命令行服务端默认开启发现并提供关闭开关。双设备防火墙、访客网络隔离和不同子网的手动回退待现场验收。使用方法和验证范围见[本地与局域网运行](deployment.md#本地与局域网运行)和[测试报告](test-report.md)。

## 3. 好友、陌生人私聊与群组

- **好友首版已实现**。可用昵称或用户名的一部分查找在线或离线账号，从结果选择申请对象。接收方接受或拒绝，服务端保存关系。好友列表显示在线状态，离线好友可收留言。解除好友关系后双方仍有自己的旧记录。
- **陌生人私聊已实现**。目标在线时可发送一个待处理的私聊请求，接收方可接受、拒绝或屏蔽。好友关系与陌生人私聊许可分别确认。取得许可的陌生人可在线聊天，离线时仍可查看历史。
- **独立群组已实现**。公共聊天室之外支持创建、搜索、请求入群、审核、邀请、退出、转让管理员和解散。群号为 10 位数字，已有 SQLite 群组升级时换发群号。好友接受普通成员的邀请后按群设置审核，接受管理员的邀请可直接入群。每次入群补齐当时最近 100 条，退群保留已授权的历史。[群组使用说明](user-guide.md#群组)
- **信息卡片已实现**。群聊标题打开群资料、成员名单、在线人数及群组操作。群消息头像、群成员和私聊标题打开用户资料与好友操作。点击群号或用户名可以复制。当前管理员可以在完整名单中点选接任者，也可先按用户名筛选。上述操作已通过本机回归，公网操作待逐项核对。[测试报告](test-report.md#近期桌面交互回归)

## 4. 表情包、图片与文件

- **Emoji 已实现**。选择面板将 Unicode Emoji 插入草稿，沿用文字消息发送、搜索和导出。本轮表情功能以此为限。
- **图片已实现**。独立按钮打开图片选择器，支持 PNG、JPEG、GIF 和 BMP，最多 12 MiB 和 2400 万像素。气泡提供缩略图、原图预览和保存。
- **文件已实现**。附件按钮允许选择包含图片在内的任意类型文件，单个最多 50 MiB。图片和文件都须确认后才通过独立连接上传，上传成功后发布消息。提供进度、取消、临时文件清理和总磁盘配额。
- **历史与保留**。按本人的可见历史授权下载，保留其他成员的访问权。附件随归档保留，当前配额用尽后拒绝新上传。自动回收和断点续传可在以后的阶段评估，公网传输的专项结果待补记。[Emoji 与附件使用说明](user-guide.md#emoji-与附件)

## 5. 存储与数据库

**SQLite 存储已实现。** 账号与资料、好友关系与请求、私聊许可、群组与成员、聊天记录和附件元数据保存在 `ltalk.db`。附件目录保存原始图片和文件。SQLite JDBC 随服务端 JAR 打包，服务端首次启动时创建数据库和表。从文件版切换时使用独立空库。已有 SQLite 表结构 v1 可迁移至 v2，旧群号会换为 10 位数字，群授权、待处理请求和历史随之迁移。[部署说明](deployment.md#更新-jar-与复测)

1. **设计表结构与权限。** 确定初始化方式、表结构版本、索引和事务边界。消息正文存一次，私聊记录双方的可见关系，群聊按成员的历史授权区间和个人删除状态判断可见性。
2. **接入账号、好友与请求。** 先验证注册、登录、改密和资料修改，再接入好友申请、好友关系、屏蔽和私聊许可。接受申请及关系变更涉及的写入放在同一事务。逐步验证服务端重启后的数据恢复。
3. **接入群组与聊天归档。** 私聊消息和双方的可见记录在同一事务中提交。用现有客户端验证群组操作、入群补齐最近 100 条、退群后查看已授权历史、仅本人删除、分页、搜索、引用、导出及附件下载权限。
4. **完整回归与部署。** 本机已验证空库初始化、v1 到 v2 迁移、重启恢复、事务失败回滚和权限边界。本轮已有新版云端基本试用反馈。云端旧群换号、原历史保留和重启恢复待专项核对。[新版云端试用](test-report.md#新版云端试用)

若云端首屏仍慢，可分别测量服务端查询耗时和客户端等到整页显示的时间。多实例共享数据或实测写入竞争成为瓶颈时，再评估 PostgreSQL。

## 6. 日常聊天体验

| 建议优先级 | 功能 | 预期体验 |
| --- | --- | --- |
| 已实现 | 逐条显示发送结果 | 消息气泡显示发送中、已确认、发送失败或结果待确认。失败和待确认时可取回正文。安全重试仍需服务端去重语义。 |
| 已实现 | 缩短断线后的恢复路径 | 聊天页提供「重新连接」，带入原服务器与用户名。同址同账号重新认证后恢复原会话和窗口草稿。自动重连待评估。 |
| 已实现 | 按需加载历史与搜索定位 | 登录显示会话摘要与当前会话最近 20 条。上滚加载旧记录并保持阅读位置。搜索当前会话的本人可见归档，选中结果定位原消息及前后各最多 9 条。 |
| 已实现 | 会话分类与回到最新消息 | 左侧切换「公共聊天室」和「好友与群聊」，其余会话可从「列表外的会话」打开。滚离底部或查看定位结果时，输入区右上方出现回到最新消息的箭头。 |
| 已实现 | 未读定位 | 打开会话自动定位第一条未读。阅读旧消息期间可点击「有 N 条新消息」跳转。 |
| 已实现 | 引用回复与复制 | 右键复制正文或引用回复。输入区可取消引用，发出的引用可点击定位原消息。 |
| 已实现 | 消息撤回 | 发出后 60 秒内可撤回本人消息。对端在原位置看到撤回提示，已撤回的附件停止授权新下载。 |
| 暂缓 | 静音和桌面提醒 | 用户已暂缓，后续可加入按会话静音和可选的桌面提醒。 |

发送反馈、重连和连接保护的验证记录见 [当前状态](STATUS.md)。对方已读回执和找回密码仍是待讨论的后续选项。
