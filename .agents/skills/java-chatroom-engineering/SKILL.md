# Java 多人聊天室开发与验证

以目标项目的源码和运行结果为依据。沿用项目支持的 Java 版本、构建方式、通信机制和依赖。使用项目已有的技术层级解决问题。

## 从意图到交付

1. **定位现有行为。** 阅读项目约定与构建配置，确认编译目标、启动入口和测试方式。沿实际调用链追踪客户端发送 → 编解码 → 服务端连接与权限校验 → 路由和存储 → 客户端接收和展示。找出线程归属、连接状态、资源清理和既有测试。根据正常入口的调用链与可执行证据判断哪些功能已接通。资料缺失时直接读代码和测试；尚无源码时先写规格与验证方案，将项目现状标为待确认。若目标项目为 LTalk，按需读 [LTalk 实现案例](references/ltalk-example.md)。
2. **表达意图，拆解需求。** 写明谁在什么场景下遇到什么问题、完成任务后能看到什么结果。按需要拆成连接或界面行为、协议与权限、数据与恢复、并发或性能。列出要保持的契约；只有会改变范围、授权、兼容性或数据结果的不确定性才需要确认。
3. **先写规格和评测。** 每条需求记录「编号｜前置状态和角色｜触发及输入范围｜应发生的结果及接收方｜失败时的提示和状态｜验收证据」。用实际收包、断开后的名额、重启后的记录或 UI 状态定义通过条件。用例覆盖正常、边界和错误路径。涉及性能时先确定并发连接数、负载、时长及指标，采用本项目约定的阈值，记录实际测量值。
4. **让 AI 按规格实现。** 用户要求实现时，先确定修改入口，再按可验证的改动单元编写代码和补充测试。只改展示时沿用业务和网络契约；获准变更通信契约后，同步两端、相关测试和协议说明。跨线程写回状态前核对当前连接和会话归属。
5. **验证并报告。** 用现有构建方式先跑改动涉及的用例，再跑必要的回归；优先使用本机回环、临时数据目录和测试账号。实测有偏差时，查明是夹具、实现还是规格的问题。修复后重跑；需要改变意图时先修订验收边界。记录需求编号、修改位置、执行命令或操作步骤、预期与实测、证据位置，并标明 `PASS`、`FAIL`、`NOT RUN` 或 `NOT SUPPORTED`。无法自动验证时，提供可复做的人工步骤。

## 按任务选择检查

| 任务 | 实现检查 | 可执行的验收 |
| --- | --- | --- |
| 广播、私聊、群成员行为 | 从服务端确认发送身份、允许发送的条件、回显语义和接收范围。分别核对实时投递权限和可见历史权限。 | 启动至少三个客户端，发送带唯一标记的消息。按协议核对每端的数量、身份和正文。私聊或受限群消息用第三方验证隔离，在有限时间内监听其收包，若有归档再查其可见历史。并发发送时核对消息集合和协议约定的顺序。 |
| 协议解析、中文和 Emoji | 按目标项目查字节编码、帧边界、大小单位、错误策略。直接基于 TCP 流实现的协议应显式组帧，同连接串行写入完整帧。 | 自行处理组帧时，拆开一个多字节字符所在帧，再把两帧合并写入，逐条核对完整正文。补测恰好达限、超限、非法帧和中途 EOF，按契约断言拒绝、恢复或关闭。 |
| 连接、异常退出和重连 | 核对连接超时、读写失败、服务停止和重复关闭的处理；释放 Socket、会话名额、后台任务和定时器。过期回调只能影响所属连接。 | 分别触发正常退出、异常关闭及服务端停止。若支持心跳，再模拟连接保持但单向静默，依项目期限等待超时。断言正常客户端仍可聊天、旧名额可复用，且旧连接清理不会清除新登录状态。 |
| 并发、慢客户端与界面卡顿 | 检查登录占位与释放、成员变更与路由等复合操作是否同步。共享锁内避免等待网络写入。发送积压按项目的队列和拥塞策略处理；Swing 网络操作在后台，组件更新在 EDT。 | 同时发起两个同名登录或在发送时退出，按契约核对服务端的最终状态。有隔离机制时，让一个客户端停止读取，验证其他客户端仍能收发，观察对应连接的积压或清理。验证网络等待期间界面仍可操作。 |
| 历史、附件和发送状态 | 若项目支持，核对事务提交、授权读取、取消、失败清理和重试语义。明确本地提交、服务端接受、对端接收等状态分别如何确认。 | 用隔离数据复测未授权读取、传输取消、写入失败及重启恢复。断开确认链路后核对发送状态与归档；只有项目有去重契约时，才用重试验证恰好一次的行为。 |

用有限超时等待业务事件或状态，避免靠固定长延时判断成功。用例范围随任务收敛；目标项目缺少某项能力时标明适用性，按用户授权决定是否实现。

## 高风险代码的人审

变更通信协议或版本兼容契约、大范围重构连接或并发模块、改变认证授权或敏感信息处理、破坏性迁移或删除数据与现有功能、引入影响运行或部署的重要依赖时，先向人工审阅者说明受影响的客户端、数据、失败后果、隔离验证方式和回退方案。取得对具体变更的授权后再实施该部分。等待期间可读代码、设计测试和执行已授权的隔离验证。线上操作和公开发布另核对执行权限。
