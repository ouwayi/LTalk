# LTalk 局域网聊天室

按《局域网聊天项目任务拆解》实现的 Java 课程项目 MVP。一个 TCP 服务端、多个 Swing 桌面客户端，无数据库，先注册账号再登录。

接续开发或开启新对话时，先读 [AGENTS.md](AGENTS.md) 和 [当前状态与开发交接](docs/STATUS.md)。交接页记录功能基线、代码入口、最近验证和可复制的新对话提示。[开发日志](docs/DEVLOG.md) 按阶段保存决策与证据。

已实现公共聊天室、好友与陌生人私聊许可、好友离线留言、独立群组、账号与资料管理、双向心跳与手动重连、历史按需加载与搜索、未读定位、引用回复、正文复制、本人记录删除以及当前会话 JSON/CSV 导出。网络连接、收发均在后台，界面在 Swing EDT 更新。

## 环境与构建

- 技术栈：Java 单模块 Maven 工程；`Socket/ServerSocket` 阻塞 TCP；UTF-8、LF 分隔的 JSON 帧；Swing/Java2D 桌面 UI；`java.util.logging` 日志，无 Web 前端框架或数据库。
- **JDK 17 或更高版本**，须包含 `java`、`javac`；客户端需要图形桌面环境。
- **Maven 3.9.x**（Windows 可使用下面的脚本自动下载固定的 3.9.9）。
- 固定依赖：Gson **2.11.0**、JNA Platform **5.14.0**（含 JNA，Windows 原生文件选择）、JUnit Jupiter **5.11.4**（仅测试）；均由构建打包，无需另装。
- 本机完整回归使用 Windows、JDK **25.0.4**、Maven **3.9.9**，以 `--release 17` 编译。用户另在 Oracle Cloud Ubuntu 24.04 运行打包后的服务端，云端 Java 的实际版本未单独记录。

构建前确认 `java -version` 与 `javac -version` 均可运行，并将 `JAVA_HOME`（如设置）指向 JDK。运行已打包 JAR 只需 Java 运行环境。编译和测试需要完整 JDK，其他操作系统可使用已安装的 Maven。

以下命令均在项目根目录 `D:\Agent\AllProjects\LTalk` 运行（先 `Set-Location D:\Agent\AllProjects\LTalk`）。首次下载需要联网；缓存齐全后可用 `-o package`，离线 `clean` 另需已缓存 clean 插件。

```powershell
# Windows PowerShell：自动准备 Maven，构建并执行所有测试
powershell -NoProfile -File .\build.ps1

# 只运行测试
powershell -NoProfile -File .\build.ps1 test

# 依赖已经缓存后，可离线构建并测试
powershell -NoProfile -File .\build.ps1 -o package
```

脚本首次运行需要联网，将校验过的 Maven 和所有依赖放在 `.tools/`；不会将工具、缓存、JAR 提交到 Git。如果本机脚本执行策略阻止运行，可使用已安装 Maven 的通用命令：

```sh
mvn clean package
mvn test
```

构建产物 `target/ltalk-1.0.0.jar` **已包含运行依赖**。复制这个 JAR 到其他装有 Java 17+ 的设备即可运行，无需再安装 Maven。不要使用 `original-ltalk-1.0.0.jar`。

## 启动与操作

**Windows 客户端**可双击 `start-client.cmd`。构建后，`target/start-client.cmd` 和 `target/ltalk-1.0.0.jar` 可一起复制到其他 Windows 设备运行。启动器从 `JAVA_HOME` 或 `PATH` 查找 `javaw.exe`，需要 Java 17 或更高版本。

公网客户端勾选「使用 TLS 加密连接」，填写证书对应的域名或公网 IP。首次部署、更新 JAR 和复测见 [单机云部署手册](docs/deployment.md)。

先启动服务端：

```sh
java -jar target/ltalk-1.0.0.jar
# 可选参数：端口、监听 IP、最大连接数（包含未登录连接）
java -jar target/ltalk-1.0.0.jar 9000 0.0.0.0 20
```

默认账号/归档使用启动时工作目录的 `data/`。长期使用可固定数据位置，避免换工作目录后误以为账号丢失（JVM 属性在 `-jar` 前）：

```powershell
java "-Dltalk.dataDir=D:\Agent\AllProjects\LTalk\data" -jar target/ltalk-1.0.0.jar
```

当前示例启动局域网模式，默认监听所有网卡的 TCP **9000** 端口，最多 **20** 个连接。按 Ctrl+C 关闭。TLS 模式默认最多 **140** 个连接，其中最多 **24** 个未认证连接。两种模式的初始握手期限均为 **10 秒**。TLS 模式完成 HELLO 后有 **60 秒**完成认证。

服务器握手成功后（含尚未登录）两端独立探测：默认等待 **10 秒**发送 PING，收到匹配 PONG 后等待下一轮，响应超时 **20 秒**。持续静默失联按本端配置在间隔 + 响应超时 + 调度容差内断开（默认约 30 秒加容差）；界面提示手动重连，服务端清理同名与连接名额。正常聊天空闲时自动响应心跳。服务端和客户端须一起更新到支持心跳的版本。

如需调整，在服务端与客户端的 `java` 后、`-jar`/`-cp` 前添加 JVM 参数，例如：

```sh
java -Dltalk.heartbeat.intervalMillis=5000 -Dltalk.heartbeat.timeoutMillis=15000 -jar target/ltalk-1.0.0.jar
java -Dltalk.heartbeat.intervalMillis=5000 -Dltalk.heartbeat.timeoutMillis=15000 -cp target/ltalk-1.0.0.jar cn.ltalk.client.ChatWindow
```

两项均为正整数毫秒，两端可独立配置。计时包含排队与写入等待；过短设置易受系统暂停、调度延迟或网络拥塞影响。具体帧和超时语义见 [通信协议](docs/protocol.md)。

如需显示接受连接、请求类型和路由错误等调试日志（不记录聊天正文）：

```sh
java -Djava.util.logging.config.file=docs/logging.properties -jar target/ltalk-1.0.0.jar
```

Windows 可以双击启动客户端，也可以在终端传入地址和用户名。显式指定地址时直接尝试 TCP 连接并跳过发现。已有账号请在窗口输入密码，首次使用可先注册：

```sh
java -cp target/ltalk-1.0.0.jar cn.ltalk.client.ChatWindow 127.0.0.1 9000 alice
java -cp target/ltalk-1.0.0.jar cn.ltalk.client.ChatWindow 127.0.0.1 9000 bob
java -cp target/ltalk-1.0.0.jar cn.ltalk.client.ChatWindow 127.0.0.1 9000 carol
```

1. 启动先显示连接与账号页面。未指定地址时，客户端在后台查找约 2 秒。找到一台就尝试连接，找到多台时从「发现的局域网服务器」选择名称和地址，再点「连接服务器」。查找可随时取消，也可直接填写 IP 或主机名和端口。点击「最近服务器」可重用最近 6 个通过 TCP 握手的地址。
2. 密码及确认密码右侧可点「显示/隐藏」，默认隐藏；切换表单、返回聊天、清理凭据或登录成功后恢复隐藏。右侧默认填写用户名、密码登录；点击「立即注册」切换为昵称、用户名（支持随机）、密码及确认密码，注册成功后自动登录。错密码/重名可留在原服务器连接中修改后重试。
3. 登录成功进入聊天页，默认公共聊天室。左侧会话列表加载最新消息摘要，也会显示有历史的离线联系人。进入会话时加载最近 20 条，向上滚到顶部或点「加载更早消息」继续翻页，当前阅读位置保留。群聊和私聊各自保留草稿。点击蓝色按钮或 **Enter/Ctrl+Enter** 发送，**Shift+Enter** 换行。气泡显示「发送中」「已确认」「发送失败」或「结果待确认」。收到匹配的服务端回显后显示「已确认」。失败或待确认时可以点「取回正文」，替换非空草稿前会先征求确认。
4. 右键消息可「删除这条记录（仅本人）」；会话菜单可「清空当前会话记录（仅本人）」，确认后仅删除你的副本，不影响对方或其他成员，删除后重登/导出也不再出现。新产生的消息仍正常保存。「重新加载聊天记录」可在加载失败或删除结果未确认时核对。
5. 聊天上方「会话更多操作 → 导出聊天记录」导出当前群聊或与该用户的双向私聊，支持 JSON/CSV；不导出其他会话。
6. 点击左下角本人头像，进入「个人信息」可修改头像、昵称或密码。改密需填写当前密码与两次相同的新密码，新密码为 6～128 字符。成功后可继续聊天，下次登录使用新密码。菜单也可退出登录或切换账号。退出登录清除当前窗口身份及缓存、草稿，下次登录重新加载服务端未删除的历史。切换账号时先保留原账号、消息和草稿，右上角「返回聊天」可取消切换。新账号登录成功后才退出旧账号，服务端未删除的归档继续保留。
7. 左上菜单可打开连接设置和切换外观。断线后留在聊天页，点顶部「重新连接」会使用原服务器地址并预填用户名。重新登录同一服务器和账号后，恢复所选会话、草稿及当前窗口的发送状态。好友离线时仍可发送；已获许可的陌生人重新上线后可重选会话继续发送。

### 好友、私聊与群组

- 点会话列表搜索框右侧的「好友与群组」，选「查找用户」，输入完整用户名后可发送好友申请。对方离线时申请也会保存；对方登录后在「请求」接受或拒绝。好友列表显示在线状态，也可解除好友关系。双方仍可查看自己的旧记录。
- 好友离线时可直接在私聊留言，对方下次进入会话时从历史查看。给在线陌生人发送前，先在聊天标题下点「申请私聊」。双方只保留一个待处理请求。对方接受后，两人在线时可互发消息。私聊许可独立于好友关系。陌生人离线时可查看旧记录，重新上线后可重选会话。私聊菜单可以屏蔽或解除屏蔽陌生人。
- 用「创建群组」填写群名和入群审核设置，创建者成为管理员。「查找群组」可按群名查找，也可留空浏览。开放群直接加入，需审核的群由管理员在「请求」接受或拒绝。
- 群聊菜单可邀请自己的好友。好友先在「请求」决定是否接受。普通成员发出的邀请遵循群的审核设置，管理员发出的邀请获接受后直接入群。
- 群组只向在群成员投递实时消息。每次加入时最多补齐当时最近 100 条，再接收在群期间的新消息。退群后仍可浏览、搜索和导出已经授权的历史。管理员可以转让给当前成员后退群，也可以解散群组；解散后原成员仍可查看各自已授权的旧记录。
- 请同步更新服务端和客户端 JAR。原账号与消息归档可继续使用。升级后，已有私聊历史仍可查看，首次发送需取得私聊许可或成为好友。

「已确认」表示收到服务端回显。连接中断、回显超时或部分服务端错误会留下「结果待确认」。可先重连核对归档，再决定是否重新发送。归档没有发送请求编号，客户端会保留待确认气泡供核对。取回正文只填入输入框，重新发送可能产生重复消息。

界面采用分栏式会话列表、生成式字母头像、在线标记、未读徽标和左右消息气泡。聊天背景仅使用纯色或渐变。草稿保存在当前窗口。窗口窄于 760 像素时改为单列，点击会话进入聊天页，左上返回箭头回到列表。

点聊天上方的放大镜，输入正文、发送者昵称或用户名。搜索包含本人可见且尚未加载的旧记录。双击结果或选中后点「定位消息」，可查看原消息及前后各最多 9 条，蓝色边框标记原消息。点「返回最近消息」回到实时聊天。

打开有未读消息的会话会跳到第一条未读，在上方显示「以下为未读消息」。阅读旧消息期间收到新消息，可点击「有 N 条新消息」定位。未读状态跟踪本窗口收到的实时消息，登录恢复的历史沿用原来的归档读取方式。

右键消息选择「复制正文」会复制整条消息的文字。选择「引用回复」会在输入区显示引用预览，草稿可继续编辑，也可单独取消引用。发送后点击气泡内的引用可定位原消息。原消息须在本人的可见历史范围内。升级时同步更新服务端和客户端 JAR。

左侧联系人、私聊标题和接收气泡显示账号当前的昵称和头像。群聊摘要显示「昵称：最后一条消息」。悬停联系人或私聊标题可查看 `@用户名`，也可按用户名搜索联系人。对方保存资料后，已打开的客户端会同步更新，历史消息也使用新头像和昵称。加载本人授权历史时，也会同步其中离线联系人的资料。连续消息组只在首条显示昵称，在末条旁显示一个头像。组尾在可视区下方时，头像可贴在聊天区底边。只剩一小截消息组可见时，头像随气泡一起被裁切并滚出。其他人发言、日期分隔和系统提示会开始新组。

左上菜单中的「外观设置」支持浅色/深色、纯色/渐变和预设配色。点击 `#RRGGBB` 色值旁的色块，可拖动色盘选择饱和度/亮度、拖动色相条调色，也支持方向键微调和手填色值；起始色与结束色分别选择，纯色时停用结束色。修改时实时预览，点击「应用设置」后生效；取消不会改变当前外观。主菜单也可一键切换浅色/深色。暗色面板使用中性近黑色，默认聊天背景为墨黑渐变；蓝色仍用于操作强调。

两个模式分别保留所选颜色，设置保存在当前系统用户目录的 `.ltalk/appearance.properties`，重新启动后加载；该文件只包含外观参数，不保存聊天、用户标识或服务端地址。新版保存外观配置 v2，兼容读取 v1；v1 中恰为旧默认的暗色对 `#111B27 / #213347`（包括曾选同色夜蓝预设）加载时换为 `#101010 / #202020`，其他自选颜色保留，读取不改写原文件。v2 中手动选择旧色对也会原样保留。配置无效时回退到默认外观；保存失败会提示，但当前已应用的外观与草稿保留。

主菜单、新建会话和聊天更多菜单共用圆角、图标、悬停与分隔线样式，并跟随当前窗口的显示模式。切换主题不会断开网络连接，也不会改变当前会话、历史或草稿。

附件与表情面板入口保留为占位。聊天、好友、请求和群组的界面结构见 [UI 设计与扩展说明](docs/ui-design.md)。

用户名去首尾空白后为 1～20 位英文字母、数字或下划线，区分大小写。重复登录拒绝新的登录尝试，原会话继续在线。正文不能全为空白，最长 2000 个 Java `char` 单元（常见 emoji 占两个）。普通协议帧上限为 16 KiB，指定头像相关帧上限为 176 KiB。

头像图片和聊天记录另存为在 Windows 使用系统原生现代选择器，具备左侧导航与顶部地址/搜索栏，外观跟随系统；导出在同一窗口选择 JSON/CSV、自定义文件名和保存位置，已有文件需确认覆盖。非 Windows 暂保留 Swing 选择器。

## 账号与聊天记录导出

- 首次注册填写昵称、用户名、密码；用户名区分大小写，1～20 位英文字母/数字/下划线，或选择随机生成。密码为 6～128 个 Java char，允许特殊符号；服务端再次校验。注册成功后客户端自动使用返回的用户名继续登录，LOGIN_OK 后才进入聊天页。
- 登录身份绑定当前 TCP 连接，不提供可跨连接重用的 bearer token；登出/断开/心跳清理后失效，新连接必须重新验证密码。没有自动重连。旧版无密码登录已拒绝，两端须一起升级。
- 聊天上方「会话更多操作 → 导出聊天记录」在另存为中选择 JSON（默认）或 CSV、文件名及位置，仅导出当前公共群聊或选定用户的私聊。只有登录后可导出自己的归档，建议文件名含用户名和 UTC 时间戳，可修改；后台逐条分页读取并写临时文件，完成后发布（已确认覆盖采用原子替换），失败提示且不发布半份文件。
- 服务端统一保存公共聊天室消息。按需浏览和搜索包括登录前和离线期间发出的共享记录。私聊历史仅限参与双方。删除公共记录只影响当前账号的浏览、搜索和导出，共享记录继续保留给其他账号。请同步更新服务端与客户端 JAR。
- 升级时继续使用原数据目录，旧归档按原账号读取。旧版缺失的公共消息不会跨账号补入，因为旧文件无法区分未收到和已经删除。共享历史从新版服务端接收的公共消息开始。
- 界面按当前会话导出。JSON 为合法数组，每条消息独占一行，正文中的换行会转义，有引用的消息包含 `replyTo`。CSV 沿用原七列和标准转义。
- 服务端 CLI 默认数据目录为工作目录 `data/`（已忽略）；可用 `-Dltalk.dataDir=绝对路径` 指定。账号以 PBKDF2-HMAC-SHA256（600000 次、随机 16 字节盐、256 位输出）保存；昵称和散列、历史正文均保存在服务端文件，需保护并备份该目录，同一目录只允许一个服务端进程使用。程序化创建 ChatServer 默认隔离临时目录，可在 start 前调用 dataDirectory(Path) 指定持久目录。
- 局域网模式使用明文 TCP，适用于可信网络或受 VPN 保护的连接。TLS 模式在认证前校验证书和主机名，并限制连接与认证频率。私聊路由和归档键使用稳定用户名。应用协议为 v6。
- 头像原图上限为 12 MiB 和 2400 万像素。居中裁剪后，如果原图短边至少为 512 像素，保存 512×512，否则保存 256×256。聊天等界面的头像按原有布局缩放绘制。编码后上限为 128 KiB，优先保留 PNG，超过时改用 JPEG，透明区域以白色填充。旧头像可继续使用，重新选择原图上传可获得更高分辨率。

## 局域网使用

局域网模式默认开启 IPv4 发现，监听 **UDP 9001**。聊天继续使用 TCP 9000 或自选端口。连接页会显示发现结果的名称和实际 TCP 地址，注册和登录仍在原表单操作。Windows 防火墙可按所用网络配置允许服务端接收发现 UDP 和聊天 TCP。同一主机上默认只有一个进程能监听发现端口，UDP 绑定失败时仍可手动连接 TCP。访客网络、不同子网或广播受限时，请手动填写服务器地址。

```powershell
# 给局域网服务端设置可辨识的名称
java "-Dltalk.discovery.name=教室服务器" -jar target/ltalk-1.0.0.jar

# 云部署或不需要广播发现时关闭 UDP 监听
java "-Dltalk.discovery.enabled=false" -jar target/ltalk-1.0.0.jar
```

如果需要更换发现 UDP 端口，在服务端和使用命令行启动的客户端都设置 `-Dltalk.discovery.port=端口`。最近列表保存地址、端口和 TLS 选项，文件为当前系统用户目录下的 `.ltalk/recent-servers.properties`。发现数据包格式见 [通信协议](docs/protocol.md)。

服务端用 `0.0.0.0` 或本机网卡地址监听。在服务端运行 `ipconfig`，找到同一局域网的 IPv4，例如 `192.168.1.20`。**其他设备的客户端填服务端 IPv4，不能填 `127.0.0.1` 或 `0.0.0.0`。**

仅在需要的网络配置下允许 Java 或指定 TCP 端口入站；无需关闭整机防火墙。确认设备接入同一可互访网络、无线 AP 未启用客户端隔离。远端设备可用 Windows `Test-NetConnection <服务端IP> -Port 9000` 排查连通性。

用户已完成心跳加入前的**宿主机＋虚拟机跨系统测试**：宿主机运行服务端和 alice，虚拟机运行 bob、carol，基本功能反馈正常；双物理设备未测。心跳已通过本机单向丢包代理测试；2026-10-28 又收到用户反馈，虚拟机断网一段时间后可自动检测到连接断开，功能正常。实际测试日期、配置和具体耗时未提供，不视为固定秒数保证。检测到失联后手动连接；尚在检测窗口内也可先点击“断开”再“连接”。实际过程与验证范围见 [测试记录与验收清单](docs/test-report.md)。

## 常见问题与边界

| 现象 | 处理 |
| --- | --- |
| 服务端启动失败/Address already in use | 检查端口占用，或换端口并同步修改客户端配置 |
| 连接被拒绝或超时 | 确认服务端已启动、IP/端口正确；检查防火墙和设备互访 |
| USER_EXISTS | 注册时表示用户名已永久注册，请换名或登录原账号；登录时可能是原会话仍在线，先退出旧会话或等待心跳清理 |
| MISSING_FIELD / INVALID_PASSWORD | 填齐昵称（注册）、用户名和密码；密码长度为 6～128 char，服务端也会校验 |
| LOGIN_FAILED | 用户名或密码错误，检查输入及是否连接到原服务端数据目录；不区分账号不存在与密码错误 |
| WRONG_PASSWORD | 修改密码时输入的当前密码不正确 |
| NOT_AUTHENTICATED / FORBIDDEN | 前者须重新登录；后者为无权导出其他账号/无效游标，不绕过权限 |
| EXPORT_FAILED / STORAGE_ERROR | 检查输出目录、服务端数据目录权限及磁盘/历史文件；不自动重发，不删除真实账号数据试错 |
| 数据目录被占用 | 先停止使用同目录的另一个服务端；每实例使用独立目录，不靠删除锁文件绕过 |
| USER_OFFLINE | 目标已离线；好友可发送离线留言，陌生人需上线后再申请或发送 |
| PRIVATE_FORBIDDEN / REQUEST_PENDING | 私聊需许可或好友关系；待处理的申请或邀请可在「请求」查看 |
| DELIVERY_UNCONFIRMED | 服务端写入私聊目标时中断，消息可能已归档，重发前可先重载历史核对 |
| 超过连接上限后立即断开 | 局域网默认 20 个连接。TLS 模式默认 140 个总连接，其中最多 24 个未认证连接 |
| TLS 连接失败 | 核对服务端启用了 TLS，端口与证书主机名正确，并确认所用 Java 的信任库包含签发方 |
| RATE_LIMITED / SERVER_BUSY | 登录或注册过于频繁，或服务器正在处理一批认证请求。稍后重试 |
| 桌面客户端启动失败 | 需要图形桌面；服务器无桌面时仅运行服务端 |

服务端依据认证连接生成发送者和时间。每条连接独立排队发送，拥塞达到上限时关闭该连接。在线私聊的回显表示归档完成且目标连接接受投递，好友离线留言的回显表示归档完成。自动重连和已读回执仍在后续范围。
